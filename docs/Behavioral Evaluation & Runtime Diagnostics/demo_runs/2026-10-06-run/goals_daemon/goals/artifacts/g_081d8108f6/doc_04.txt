Ludeme - Wikipedia Jump to content From Wikipedia, the free encyclopedia Basic unit of play A ludeme is an abstract fundamental unit of play in a game , as distinct from an "instrument of play" which forms part of the equipment with which a game is played. An example of a ludeme is the L-shaped movement of a knight in chess , whereas the knight itself is an instrument of play. [ 1 ] It is used to describe games between game scholars or to AI , and is a major part of systems aimed at developing General Game Playing AI. Definition [ edit ] Ludemes have three main properties that remain consistent between all users of the term: Discrete: A ludeme can be identified as one piece of information about a game (For example, the L-shaped movement of a knight is one self-contained mechanic). Transferrable: A ludeme can be moved to different parts of a game and can be moved between games. Ludemes can also be translated into understandable descriptions that can transfer information between people. Contrastive: Changing a ludeme creates a significant change in the way a game is played. [ 2 ] [ 1 ] Additionally, some users of the term differentiate between Atomic Ludemes, ludemes that cannot be broken down into smaller elements, and Compound Ludemes (also called Ludemeplexes), which are ludemes made up of other sub-ludemes. By this definition, entire games can be categorized as ludemes because they are discrete, transferrable, and contrastive elements of play that are made up of sub-ludemes. The use of Compoud Ludemes, however, is not universally agreed upon; some figures in game studies define ludemes as only being Atomic. [ 2 ] Origin [ edit ] The term was originally coined by French game writer Pierre Berloquin [ fr ] . [ 3 ] Alain Borvo, one of the first to use the term in writing, defines it as a 'type rule' such as the method of trick-taking in a card game or the leap capture in a board game. [ 3 ] [ 4 ] Ludeme as a term is considered similar to the term "meme" coined by Richard Dawkins in The Selfish Gene , and as such it is sometimes referred to as a "game meme" because both have the property of transmitting throughout human culture. While the two terms bear similarities, it is unclear if the term ludeme was derived from Dawkins's definition of a meme. [ 1 ] Uses [ edit ] Ludii General Game System [ edit ] Ludemes are used as the foundation of the Ludii General Game System which is programmed in Java . Using Ludii's description language, a game can be written out using ludemes in a way that a computer can interpret to make the game playable by humans or AI. Ludii is built using a class grammar approach, where each ludeme described corresponds to a Java class of the same name. [ 5 ] [ 6 ] The Ludii General Game System is primarily used for developing General Game Playing AI that can play any game, as opposed to AI designed to play a specific game. Ludii is generally considered easier to write and read compared to it's counterpart General Game Systems such as the Stanford Game Description Language (GDL) and Regular Boardgames (RBG). [ 3 ] [ 5 ] The Ludii system uses a specific syntax to write out games using ludemes. Each game that can be processed by the Ludii General Game System contains information about the game's Players, Equipment, and Rules, in roughly the following structure. [ 5 ] Players: Lists all of the players in the game, including a dummy player that acts as "nature" or randomness. This is also where the game's turn structure is defined (Alternating, Simultaneous, or Realtime). Equipment: Lists all equipment used, divided up into two categories: Containers: Game pieces that "contain" other game pieces (such as the game board). Component: individual pieces of the game (such as pawns) Rules: Lists all the rules of the game, divided into three categories: Start: A sequence of actions to perform at the beginning of the game to set it up. Play: The actions that each player takes on their turn. End: A list of all the end conditions of the game, and their result (win, loss, etc.). For Example, Tic-Tac-Toe described in Ludii syntax would look as follows: [ 5 ] ( game "Tic Tac Toe" ( players 2 ) ( equipment { ( Board ( square 3 ) ( square ) ) ( piece "Disc" P1 ) ( piece "Cross" P2 ) } ) ( rules ( play ( to Mover ( empty ))) ( end ( line 3 ) ( result Mover Win )) ) ) This description of the game includes that it has two players, uses a 3 x 3 square board and two different types of pieces used by different players called "Disc" and "Cross," and for rules, players can place a piece in an empty cell during their turn, and the game ends when a line of three pieces of the same type is created, resulting in a win for the player who made the line. [ 5 ] The Ludii program also tracks the "game state," which changes based on the "Play" actions that are taken by human or AI players. [ 5 ] Digital Ludeme Project [ edit ] The Digital Ludeme Project is a research project launched by the University of Maastricht in 2018. It's goal is to reconstruct ancient games using the Ludii General Game System in combination with AI systems. Using the Ludii system, researchers are able to use AI to find statistically likely rulesets for ancient games that don't have recorded rules based on the game's components or the geographic region it was found in. The project also aims to map out where different games and ludemes might have been found throughout history.
