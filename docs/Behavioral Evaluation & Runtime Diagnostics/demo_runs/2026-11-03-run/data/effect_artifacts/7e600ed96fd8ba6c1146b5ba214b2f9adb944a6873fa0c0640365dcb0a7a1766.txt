The deep structure of a linguistic expression is a theoretical construct that seeks to unify several related structures. For example, the sentences "Pat loves Chris" and "Chris is loved by Pat" mean roughly the same thing and use similar words. Some linguists, Chomsky in particular, have tried to account for this similarity by positing that these two sentences are distinct surface forms that derive from a common (or very similar [ 1 ] ) deep structure.
