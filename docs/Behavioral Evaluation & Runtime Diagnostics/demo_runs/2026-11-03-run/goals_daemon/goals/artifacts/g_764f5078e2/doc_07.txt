List of Clarissa Explains It All episodes - Wikipedia Jump to content From Wikipedia, the free encyclopedia This is a list of episodes for the Nickelodeon children's sitcom Clarissa Explains It All , which aired from 1991 to 1994. The series lasted five seasons, each producing thirteen episodes. [ 1 ] Many of the episodes were shown in a different order than the order in which they were produced. Both the production numbers and the airing numbers are listed. A total of 65 episodes were produced. As of July 2018 [ update ] , only the first season is available on DVD.
